# 분석 준비도 게이트 · 배너 규격

## 1. 6차원

1. **수량** — 질문에 충분한 관측(쿼리·노드·경로·시점)이 있는가
2. **커버리지** — 시드·동의어·엔티티·세그먼트가 한 쿼리 시점을 넘어서는가
3. **목적 적합** — 증거 유형이 요청한 결론과 맞는가(트렌드엔 시점 비교, 여정엔 경로)
4. **안정성** — 한 이상치·이벤트·브랜드·채널·시즌이 결과를 지배하지 않는가
5. **품질** — null·중복·인코딩·locale·시점이 통제됐는가 · 시드 오염이 제거됐는가
6. **다양성** — 물질적 발견에 둘 이상의 신호가 있는가

## 2. 목적별 점검

- 트렌드: 비교 가능한 시점 + 일관된 범위 · 공통 최신 월 통일
- CEP/KBF: 서로 다른 맥락·기준 신호 복수(반복 구절 하나 아님) · 상황형은 캔버스 완주 여부
- 브랜드: 방어 가능한 엔티티 집합(사전) + 맥락 · 원시 언급 수 아님 · 채널 분리
- 여정: 의미 있는 경로 커버리지 · 희소 엣지로 퍼널 추론 금지
- RTB: 출처·주장 추적 가능
- 총량: 노이즈율 **볼륨 기준** 재확인(개수 기준은 과소평가)

## 3. 상태와 행동

| 상태 | 행동 |
|---|---|
| READY | 진행 |
| READY WITH LIMITS | 경계를 명시하고 그 안에서만 결론 |
| EXPAND | 빠진 증거 패밀리를 **하나씩** 추가(동의어 → 상황어 → 브랜드 → 여정) |
| NARROW | 세그먼트·용도·주장 범위를 줄이고 배너에 명시 |
| NOT READY | 결론 대신 방법·데이터 요청 |

하드 표본 임계는 두지 않는다 — 목적별 임계를 쓰고 근거를 밝힌다.

## 4. 배너 규격 — 프롬프트로 못 막는 데이터 제약 (항상 점검)

데이터를 열어봐야 알 수 있어 사전 지시가 불가능한 항목. 해당되면 배너에 ①②③으로 나열한다.

| 제약 | 서술 방식 |
|---|---|
| **인구통계 부재** (gl=us·jp) | "데이터 공백"이 아니라 **"데이터 사양"** · 세그먼트는 과업·구매기준·여정 근거로 |
| **볼륨 커버리지** | 롱테일 다수가 보고 임계 미만(예: 12.2%만 볼륨) → 규모 아닌 언어 근거로만 · 비율 명기 |
| **동의어 볼륨 중복** | 동의어군이 같은 볼륨 공유 → dedup 전/후 수치 병기 |
| **오타·띄어쓰기 변형** | 별도 키워드로 독립 볼륨 반환(예: "전기 자건거" 57,363/월 = 헤드텀의 23%) → 합산 여부와 근거를 배너에 명시 |
| **인물·광고 모델 결합** | "○○(연예인) 카테고리" 쿼리는 브랜드 미확인 시 총량·SoV 제외하고 해석 보류 카드로 |
| **범용 허브 노이즈** | cluster 결과의 초대형 무관 노드(마켓플레이스·커뮤니티·기업 노드) 총량 제외 · 제외 목록 공개 |
| **시드 교체** | 발화 시드가 금지 목록이면 대체 시드와 사유 |
| **월 그레인·지연** | 최신 월·지연 주수 · 주간 경보 불가 |
| **적재본 사용** | 출처·스냅샷 시점 · "추가 크레딧 0" |
| **검색≠행동** | 구매·계약·방문·CS 인입이 아님 |
