# 산출물 패턴 (④ 계층) — 텍스트 구조 · HTML 스파인 · 조사원 인사이트

## 1. 텍스트 기본 구조 (즉답형)

```
### {대상} · {잡} 분석

[조사원 인사이트 3~5개 — 사용자가 안 물어도 먼저]
1. [세그먼트 격차] … → 시사점
2. [리스크 신호] …
3. [라이징] … / [기회 공백] … / [진입점 지배] …

**범위·준비도** — gl, 기간, 실행 주체 · 준비도 상태 + 제약 ①②③
**핵심 지표** 표 (실측 우선)
**결정구조** (신호 있는 층만) / **시사점** / **권고 액션** (실행 주체 관점)
**한계·다음 데이터** / **크레딧** — 이번 소진 N (커넥터별) · 월간 누적 M
📌 다음 조사 추천 — (강한 추천) … / (대안) … / (대안) … · 추가 호출 없이 답할 수 있는 범위
```

조사원 인사이트 5분류: 세그먼트 격차(누가 지배·격차) · 리스크 신호(부정·회피·CS) · 라이징(volume_trend·YoY·spike)
· 기회 공백(볼륨 극소·미커버) · 진입점 지배(어느 CEP·의도가 편중). 톤은 간결한 비즈니스체(`00_Context/voice.md`) —
발견을 앞에, 추정은 `[가정]`, 옵션 나열 대신 "가장 임팩트 큰 것부터".

## 3. HTML 리포트 스파인 (`report-template.html` · `render_report.py`)

공통: 마스트헤드(실행 주체 배지 필수) → 리드(실제 수행한 잡만 서술) → 준비도 배너 → KPI 4장 → 섹션 →
기회 백로그 → 부록(호출 순서·호출 로그·비용 보고서) → 푸터(방법·크레딧 + 가드레일). 섹션 번호는 포함된 순서대로 01부터.

| 분석 단위 | 섹션 순서 |
|---|---|
| **세그먼트(기본형)** | 수요 트렌드·시즌성 → 브랜드별 검색 점유율(SoV, 브랜드+모델 합산) → 소비자 결정구조(6카드) → 검색 여정(CDJ) → 기회 백로그 |
| **카테고리(변형)** | 수요 트렌드·시즌성 → **시장 규모·세그먼트 구성(TAM)** → 전체 SoV(Generic 분리·세그먼트 역전 하이라이트) → **검색 의도 구성(Intent Mix)**(결정구조 대체 가능) → 기회 백로그 |
| **혼합** | 세그먼트형 + 카테고리 맥락 1섹션(TAM 요약) |

규칙 — 수행한 잡의 섹션만(빈 섹션을 일반론으로 채우지 않음) · 차트 inline SVG(24개월) · 수치마다 MEASURED/DERIVED
배지 · SoV "검색량 기준 근사" + 채널 분리 + 매칭 별칭 공개 · 결정구조 카드는 볼륨 내림차순, 해석 보류 카드 맨 뒤 ·
백로그 3분류(지금 대응/지켜볼/위험) + 임팩트 배지 L(10만+/년)·M(1만~10만)·S(1만 미만) · 헤딩 "한국어 명사구 + (표준 용어)".

파일명: `90_Output/{대상}-{리포트 유형}-{YYYY-MM-DD}.html`. 저장 후 Artifact 게시.
