# 엔티티 사전 규칙 (② 계층) — brand-map 작성·별칭 정규화·노이즈/채널 분리

범용 스킬은 산업 사전을 갖지 않는다. 대신 **사전을 만드는 규칙**과 빈 템플릿(`dictionary/brand-map.md`,
`dictionary/E0_사전.csv`)을 제공한다. 분석마다 대상 카테고리의 브랜드·채널·노이즈를 이 규칙으로 채우고,
오버레이가 있으면 그 `references/brand-map.md`가 정본이다.

## 1. brand-map.md 표기 계약 (`brand-map-md/v1` — 파서: `lima-agents/lib/canon.py` 단일 정본)

```
- **대표명 (영문)** — ×: 사명 별칭, 사명 별칭 / ○: 서브브랜드 별칭(영문), 제품 라인
```
- **×** 사명 별칭 — 단독 쿼리("삼성"·"소니")는 카테고리 의도인지 주가·채용인지 불명 → SoV 분모·분자 **제외** + `[가정]`
- **○** 서브브랜드·제품 별칭 — 단독 쿼리("비스포크"·"bravia")도 카테고리 의도가 명확 → **유지**
- 대표명은 기업/브랜드 수준으로 통일. "소니 tv" 같은 카테고리 결합형을 대표명으로 쓰지 않는다 —
  경쟁 브랜드 간 **별칭 폭이 대등**해야 비대칭이 없다(kr은 한글 별칭 필수).
- 리포트 브랜드 행에 **실제 매칭한 별칭 목록**을 표기한다(폭 대등성 검증).
- **브랜드당 한 줄** — 파서는 `- **이름** — 본문` 한 줄만 읽는다. 별칭을 다음 줄로 이어 쓰거나 표로만 쓰면
  **조용히 누락된다**(실측: 줄바꿈으로 제품 라인 별칭 누락 · 표 형식이라 브랜드 0건). 한 줄에 두 브랜드를 쓰면
  뒤 브랜드 별칭이 앞 브랜드로 오귀속된다. 파서가 진단(`diagnostics`)으로 드러내니 0건으로 만든다.
  브랜드 목록의 원천이 E0 사전이면 손으로 옮기지 말고 E0에서 생성한다.

## 2. 브랜드가 아닌 것 — 분리해서 센다

| 유형 | 예 | 처리 |
|---|---|---|
| 판매·중개 채널 | 쿠팡·하이마트·amazon(리테일 문맥)·네이버쇼핑·비교 사이트 | SoV 분모 제외 · "판매·중개 채널" 배지로 규모 참고 |
| 리뷰어·커뮤니티 | 노써치·귀곰·디시·클리앙·퀘이사존·reddit | RTB 원천(검증 관문)으로 분류 |
| 기업 노드 | 채용·주가·로그인·고객센터 단독 | 노이즈 |
| 이중 성격 | amazon(fire tv=기기 브랜드 / "at amazon"=채널) | 문맥으로 구분, 규칙을 note에 |

**전업 브랜드 예외** — 한 카테고리만 파는 브랜드(예: 모토벨로=전기자전거 전업)는 기업명 단독 쿼리도 카테고리 의도일 가능성이 높다.
규칙상 ×로 제외하되, 단독 볼륨이 결합 쿼리 합보다 크면 **포함 시 순위 변화를 리포트에 병기**한다(2026-08-22 실측: "모토벨로" 단독
48,356/월 포함 시 SoV 24%→43%로 1위 역전). 분석 전 사용자에게 취급 규칙을 확인받는 것이 가장 안전하다.

사전 공백은 SoV가 아니라 **분모**를 먼저 망친다 — 미등재 브랜드 7만+가 논브랜드로 오분류돼 진입 규모가
2.2배 과대 계상된 실측. 상위 연관어에 낯선 고유명사가 보이면 웹 검증 후 사전에 append.

## 3. 동음이의·동의어

- **동음이의어**는 `keep_only` 결합형만 집계: 미니→"미니 쿠퍼" / 드럼→"드럼세탁기" / dryer→"clothes dryer" /
  MLB→"MLB 모자" · 코치→"코치 가방". 단독어 적합률 프로브로 오염을 확정한 뒤 결합형을 실측해 고른다.
  선언만 하고 결합형을 brand-map에 넣지 않으면 그 브랜드는 0건으로 집계된다 — 정본 공백이다.
- **동의어군 합산**(소고기=쇠고기, 계란=달걀, 노트북=랩탑)은 볼륨 dedup 후(같은 볼륨 공유) 서술.
- **합산 금지 쌍**(저당≠무설탕, 새벽배송≠샛별배송, 중고≠리퍼)은 사전 note에 명시.
- **Generic(무브랜드)** = 브랜드 별칭 미매칭 쿼리(`alias-nonmatch` 계산 규칙 — 어휘 목록 아님). 카테고리
  리포트 SoV에서 Generic 행을 분리 표기한다.

## 3.1 매칭 오탐·한계 — 채택 전에 점검한다

- **부분 문자열 오탐 점검** — 별칭·결합형을 사전에 넣기 전에 코퍼스와 프로브 쿼리에 대 보고,
  다른 뜻의 쿼리에 부분 일치하는 표기는 채택하지 않는다. 식품·가전·의류 세 업권에서 실측됐다:
  `고등어 통조림`→`조림`, `hashphotos`→`hp` · `엔비디아`→`엔비`, `가니티쳐마켓`→`가니 티` ·
  `코리아 아미 티셔츠`→`아미 티셔츠`. 영문 별칭은 파서가 단어 경계로 막지만 한글 별칭은 막지 못한다.
- **결합형은 사이 수식어를 놓친다** — `○○ 원피스`는 `○○ 여름 원피스`에 걸리지 않는다.
  결합형만 등재한 브랜드는 실측 결합형 대비 포괄률을 기록하고 SoV를 **과소 집계**로 표기한다(실측 포괄률 62~83%).

## 4. E0_사전.csv 포맷 (`e0-csv/v1`)

```
class,label,aliases,note
Brand,삼성,삼성전자|samsung|비스포크,× 삼성·삼성전자·samsung / ○ 비스포크
Channel,쿠팡,coupang|쿠팡 로켓,판매·중개 채널 — SoV 분모 제외
Noise,tv,티비,매체 다의 — 단독 금지 · 대체: tv 추천·스마트tv
Noise,이사,,생애 이벤트 단독 금지 · 대체: 신혼 가전 리스트
Synonym,노트북,랩탑|laptop,볼륨 dedup 후 합산
```
`class` ∈ {Brand, SubBrand, Channel, Reviewer, Noise, Synonym, Anchor}. aliases는 `|` 구분. append-only.

## 5. 시장별 차이

브랜드 구성은 gl마다 다르다(us TV 상위에 amazon·google·roku 기기 브랜드, kr엔 없음). gl별로 사전 절을 나누고
한 나라 사전으로 다른 나라를 집계하지 않는다.
