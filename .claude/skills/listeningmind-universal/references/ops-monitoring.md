# 운영 모드 (④ 계층) — 월간 모니터링 · 구조 변화 감지 · 크레딧 원장

분석(발견)이 아니라 **정기 감시**로 들어온 발화("○○ 검색 이상 알려줘", "라이징 모니터링", "불만·환불 검색 감시")는
리포트 스파인 대신 이 운영 스택을 탄다. 리테일 카테고리 실측(2026-08)에서 범용으로 승격.

## 1. 데이터 사양부터 고지

- LM 시계열은 `keyword_info` **월 그레인 48개월**뿐. `path_finder` time_point도 분기 단위. 주간·일간 없음.
- 갱신 **월 1회 롤링, 지연 3~7주**, 시드별 반영 시차 상이 → 판정 전 **공통 최신 월로 통일**.
- 따라서 **주간 실시간 조기경보는 만들 수 없다.** 주간 트리거는 내부 데이터(콜센터·앱 로그·VOC 텍스트)의 영역이고,
  LM은 내부 VOC가 설명하지 못하는 **구조·이유**를 월 단위로 채우는 층이다. 이 역할 분담을 산출물 첫머리에 쓴다.
- 폐기한 설계: 매주 `volume_avg`를 축적해 주간 시계열을 만드는 방식 — 갱신 전까지 같은 값이 돌아와 계단 함수가 되고
  그 위의 z-score는 무의미.

## 2. 두 모드

| 모드 | 대상 | 주기 | 판정 규율 |
|---|---|---|---|
| **트렌드 모니터링** | 시드군(카테고리·상황·속성) | 월 1회 | 코퍼스 중앙값 대비 **상대 YoY** 4단계(급등/성장/성숙/쇠퇴) · spike z≥3 레벨시프트 의심 · 볼륨 하한 1,000 |
| **구조 변화 감지**(VOC·CS·이슈) | 브랜드 결합 이슈 시드(고객센터·환불·재고·오류) | 월 1회 (주간 크론은 `--poll` 갱신 도착만) | 기준선(직전 6개월) **z-score** — z≥2 주의 · z≥3 경보 · z≤−3 급감 · 볼륨<500은 절대 증분(≥200 & 2배) 보조 · 같은 그룹 2개 이상 동시 → 그룹 경보 |

## 3. 실행 순서 (설계 절차)

> 아래 2·3의 센티널 크론·판정표 산출 스크립트는 이 패키지에 포함돼 있지 않다 — 절차 설계 기준으로 제공하며,
> 동봉 도구로는 `seed_check.py --mode cs`(이슈 시드 검증)와 저장 스냅샷 `--replay`(0크레딧 재채점)를 쓴다.
> 판정표 자동화가 필요하면 이 절차대로 스크립트를 작성하거나 공급사에 요청한다.

1. 시드 등록 — `dictionary/E0_사전.csv`에 `Anchor`/이슈 행 추가(브랜드 결합형 필수) → `seed_check.py --mode cs` 검증
2. 주간 크론 — 센티널 1키워드 `keyword_info ads_metrics`(1크레딧)로 새 월 도착 감지(`--poll`)
3. 도착 시 본 실행 — 시드당 keyword_info all(10크레딧) → 판정표 `ops/alert_latest.csv` · 이력 `ops/alert_log.csv`(append-only)
   · 저장 스냅샷만 쓰는 `--offline`이면 0크레딧
4. **알림 전 교차 검증** — 내부 데이터와 대조. 검색 변화만으로 "불만 증가"를 단정하지 않는다
5. 경보 시드는 path_finder로 저니 심화(시드당 6~10천) → 무엇으로 새는지 확인 → FAQ·앱·콘텐츠 백로그

## 4. 강제 문구

"월 그레인·3~7주 지연 — 주간 실시간 경보 아님 · 검색 관심의 변화이며 실제 인입·매출·건수 아님 · 인과 단정 금지"

## 5. 크레딧 원장

호출마다 `{ts, tool, params, cost}`를 `ledger.json`에 누적하고, 예산(`--budget`)이 있으면 호출 **전** 예상치를 확인해
초과 시 중단한다. 리포트 푸터의 "이번 분석 소진"은 원장 합산, "월간 누적"은 마지막 응답의 `used_credits`.
리플레이(`--replay DIR`)는 저장 스냅샷으로 0크레딧 재실행 — 임계·규칙 튜닝은 항상 리플레이로.

## 6. 주간 신호 보완 후보 (미검증)

네이버 데이터랩·구글 트렌드의 일/주 **상대 지수**는 급증 감지엔 충분하다. LM 월간 절대 볼륨 + 외부 주간 상대 지수
하이브리드는 이용 조건 확인 후 아키텍처 과제로.
