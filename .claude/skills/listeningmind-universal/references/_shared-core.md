# _shared-core · 표현 규율 정본 (③ 계층 · Single Source of Truth)

> 이 파일은 범용 스킬과 모든 오버레이가 공유하는 **유일한 규율 정본**이다. 잡 플레이북·프레임·템플릿은
> 규율을 다시 쓰지 않고 여기만 참조한다. 규칙을 바꿀 땐 이 파일만 고친다(중복 정본 금지 → 드리프트 방지).
> 여러 업권 분석과 CEP Finder 실측에서 얻은 교훈을 반영했다.

## §0. 도구 로드 (항상 먼저)

핵심 커넥터 4개(`keyword_info`·`intent_finder`·`cluster_finder`·`path_finder`)와 보조 커넥터 2개(`serp`·`trend_finder`)는
환경마다 등록 이름이 다르다.
본문에서는 bare 이름으로 부르되 실제 호출은 환경에 맞게 한다.

- **Claude.ai 커넥터**: `ListeningMind:keyword_info` … (설정에서 켜면 지연 로드)
- **MCP 런타임(Claude Code)**: `ToolSearch`로 스키마 로드 — `mcp__…__keyword_info`
- **HTTP 직접 호출**: `LM_API_BASE`(환경변수 → 기본값=운영 엔드포인트) + `LM-API-KEY` 헤더.
  키는 `00_Context/.lm-api-key` 파일로만 보관한다.

**미연결 폴백** — 도구가 로드되지 않으면 접근권 문제가 아니라 커넥터 미연결이다. 연결 방법을 안내하고,
연결 전에는 실측치를 지어내지 않는다. 방법론만 설명하거나 웹 일반 개요로 임시 대체하되 "실측 아님"을 분명히 한다.

## §1. 정직성 규율

- **null은 0이 아니라 "데이터 없음"** — 추측 금지, `[없음]`으로 표기.
- **알고리즘이 안 준 등급을 만들지 않는다** — HOT/급상승/high 임의 라벨 금지. 연속 수치를 그대로 인용하고
  강도 해석은 도메인 맥락으로. 통계 임계를 쓰는 파생 지표(z-score·상대 YoY 등)는 임계를 밝힌다.
- **추세는 단기만 제시하지 않는다** — `volume_trend` 같은 단기 지표에 장기 방향(24~48개월)을 병기.
- **의도 태그 `{i,n,c,t}`는 present/absent** — 비율이 아니다. 백분율·곱셈 금지, 동시 1 가능.
- **경로·관계는 집계 그래프** — 개인의 실시간 이동이 아니다. "이탈/전이/병목"은 모델 통계로 인용.
- **시점 확인** — `request_at`으로 데이터 시점을 파악하고 학습 데이터의 외부 사건·연도를 투사하지 않는다.
  과거 비교는 `time_point`(curr/3m/6m/9m/12m)로.
- **부재 ≠ 반증** — 검색에 없다고 수요가 없는 게 아니다. 단, 캔버싱(상황 어휘 전수 프로브)을 완주한 뒤의
  부재는 `[실측]`으로 말할 수 있다("이 카테고리에 선물형 진입은 최대 43/월").
- **데이터로 뒷받침되지 않는 주장 금지** — 커넥터가 준 값의 범위 안에서만 결론. 대안 설명·맹점을 밝힌다.

## §2. 출처 라벨 정책 (5등급)

| 라벨 | 뜻 | 예 |
|---|---|---|
| `[실측]` MEASURED | 도구 응답값 그대로 | volume_avg 12,670 |
| `[파생]` DERIVED | 합산·계산·해석값 | SoV 비중, YoY, 군집 라벨 |
| `[가정]` ASSUMPTION | 데이터가 없어 둔 전제 | "기업명 단독 쿼리는 카테고리 의도 불명으로 제외" |
| `[없음]` MISSING | null·미반환·사양 밖 | us demography |
| `[fact]` | 외부 공표값(공시·통계·법령) | 시세, 인증, 규제 조항 |

근사·추정이면 "정밀치 아님"을 명시한다. 리포트 배지는 MEASURED/DERIVED 두 종으로 압축하되 본문에서
가정·없음을 숨기지 않는다.

## §3. 크레딧 규율 — 원장·단가·용어

- 호출 1건 비용 = 응답 `cost_detail.total_cost`. **이번 분석 소진** = 호출별 `total_cost` 합산(`[실측]`).
- `used_credits` = **월간 누적 사용량**(당월 리셋). 잔여량이 아니다 — "남은 크레딧/잔고"로 제시 금지,
  "계정 누적" 표기도 금지("월간 누적"으로).
- **단가는 여기 적지 않는다.** 근거 순서 — ① 공개 API 문서 https://listeningmind-data-api.ascentlab.io/
  ② `lima-agents/references/daas-api-overview.md` §크레딧 참고(스냅샷) ③ 응답 `cost_detail.total_cost`(실제 청구).
  셋이 어긋나면 **API 문서가 이긴다.** 예산은 `scripts/credit_estimate.py`로 먼저 낸다.
- **과금 단위 오해 방지** (수치가 아니라 단위 — 이건 바뀌지 않는다): `cluster_finder` 는 관계 수가 아니라
  **반환 고유 키워드 수**, `path_finder` 는 경로 수(limit)가 아니라 **경로에 등장한 고유 키워드 수** 기준이다.
  `path_finder` 가 최고가, `intent_finder`·`*/keyword_list` 가 가장 싸다.
- **순서가 비용 구조다** — 30크레딧 캔버스(intent_finder 프로브)가 20,500크레딧 실패 호출을 대체한 실측이 있다.
  넓은 호출(cluster_finder limit 5000·path_finder) 전에 항상 저비용 프로브로 구조를 본다.
- 사용자가 "크레딧 N 이내"를 말하면 하드 상한이다. 상한을 넘길 호출은 실행 전 고지·확인.

## §4. 국가·언어·데이터 사양

- `gl`(kr/us/jp)과 응답 언어는 독립. 여러 나라 비교는 gl별로 따로 호출 — 한 나라 데이터로 다른 나라를 추론하지 않는다.
- **인구통계(성·연령)는 gl=kr 전용.** us·jp는 `demography` 미반환 — "공백"이 아니라 **"데이터 사양"**으로
  서술하고, 세그먼트 판단은 쿼리 언어·맥락(과업·구매기준·여정) 근거로만.
- **시계열은 월 그레인 48개월뿐.** 갱신 월 1회 롤링, 지연 3~7주, 시드마다 마지막 월이 다를 수 있다 →
  비교 전 **공통 최신 월로 통일**. 주간·일간 시계열은 없다.
- 시드는 순수 검색어만 — "시장/분석/트렌드/조사/리포트" 같은 메타 단어를 제거한다.

## §5. 호출 안정성

- **커넥터 동시 요청 = 1.** 병렬 호출은 `Too Many Requests` → 직렬. (keyword_info 배치는 래퍼가 max 3으로 통제)
- 첫 조회는 수 초~수십 초. 넓은 `limit`·`hop=3`은 응답이 큼 → 좁게(hop=1·limit 30~100) 구조 먼저.
- 빈 결과(`rels:[]`, `communities:{}`, `data:[]`)는 대개 (a) 인코딩(유니코드 이스케이프 금지, 실제 문자로)
  (b) 해당 국가 데이터 없음 (c) 희소 키워드 → 인코딩부터 점검.
- 응답 원본은 `99_Scratch/<분석>/api/<커넥터>_<gl>_<일시>_<시드>.json`으로 보관 — 리플레이(0크레딧)의 근거.

## §6. 산출물 형태 결정

- **텍스트(기본)** — 좁고 즉답형. 핵심 수치 + 해석을 산문으로.
- **HTML 리포트** — "대시보드/리포트/정리/시각화" 요청 · 분석 축 3개 이상 · 여러 잡이 섞인 요청.
  `scripts/render_report.py`로만 렌더(§7). 다면적인데 산문만 내는 것은 형태 미충족.
- **인터랙티브 탐색** — 훑어보기 원하면 `lima-agents` Explorer로 안내.

## §7. 렌더·차트 규칙

- 차트는 외부 CDN·라이브러리 없는 **inline SVG**(결정론). Chart.js·D3 금지 — 이유 셋:
  ① 어휘 검사·제목 검토·숫자 대조는 HTML 텍스트를 읽는데, 캔버스 차트의 축·범례·값은 그림이라 검사에 안 보인다(렌더러가 HTML에 써 넣은 SVG는 `<text>`로 남는다 — 그래서 좌표는 렌더 시점에 계산하는 것이 기본)
  ② y축 0 기준·전 계열 최대값 정규화 같은 시각화 규칙을 라이브러리 기본값이 아니라 렌더러 코드가 고정한다(예: Chart.js 라인 차트는 0 기준이 기본이 아니다)
  ③ 오프라인·첨부 파일·스크립트를 막는 미리보기에서도 차트가 그려지고, 같은 데이터면 같은 그림이 나온다(재현성 · 인쇄 품질)
  lima-agents 질문 코드 리포트(Report 모드)를 포함한 모든 HTML 산출물에 적용한다(2026-10-13 통일 — `lima-agents/reports/_shared/chart-helpers.js`).
- 수요 차트는 기본 **최근 24개월**만(장기 아웃라이어가 y축을 압축) · dual-axis 금지 · 시리즈 색 3슬롯.
- 노드·행이 많으면 상위 N + "기타" 롤업 + 「전체 K개 중」 표면화. `completeness<0.5`·null이면 그 차트만
  생략하고 표·문장으로.
- LLM은 **서술만** 쓰고 차트·레이아웃은 렌더러가 결정론으로. 셸·sed·f-string으로 템플릿에 JSON 직접 주입 금지
  (개행이 `\n` 리터럴로 깨져 JS SyntaxError).
- 스파인: 마스트헤드(실행 주체) → 준비도 배너 → KPI → 수행한 잡 섹션 → 기회 백로그 → 부록(호출 순서·호출 로그·비용 보고서) → 방법·크레딧·가드레일 푸터.
- 헤딩은 "친화적 한국어 명사구 + (표준 용어)" 병기 — 브랜드별 검색 점유율(SoV) · 검색 여정(CDJ).

## §8. brand style

색·차트 유형·캡션 규칙은 조직 brand style에 따른다(오버레이에서 토큰 교체). 접근성: 범주 색 고정 순서,
텍스트는 텍스트 토큰, 상태색은 예약.

## §9. 사용자 주권 포크

데이터를 봐야 드러나는 갈림길(범위·비교군·청중·산출물이 바뀌는 경우)에서 **선택지는 생성하되 결정은 사용자**.
호출 **후에만** 생성하고 각 선택지에 근거 패턴을 인용한다. 한 분석에서 stop-and-ask **2회 이하** — 동시 발생
시 가장 물질적인 하나만 묻고 나머지는 정직한 기본값 + 문장으로 밝힌다. 사용자가 자율 기본값을 요청하면
가장 좁은 방어 가능한 선택지를 택하고 가정을 명시한다.
