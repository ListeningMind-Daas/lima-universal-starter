# 사용자 질문 응답 패턴 · Q&A Playbook

이 스킬의 핵심 역량 · 사용자 질문에 <b>정확히·근거 있게 답변</b>. 학습 데이터 발화 금지 · 반드시 DaaS 데이터 근거.

## 사용자 요청 3가지 모드 분기

첫 응답에서 사용자 요청을 3모드로 분류:

| 모드 | 사용자 발화 예 | 실행 API | 산출 |
|---|---|---|---|
| **A. 그래프 조회**| "○○ 시장 클러스터 그래프", "키워드 네트워크", "검색 군집" | cluster_finder + keyword_info | 인라인 인터랙티브 그래프 + 요약 |
| **B. 키워드 정보**| "○○ 키워드 정보", "○○ 검색량", "○○ 트렌드", "○○ 페르소나" | keyword_info(all) | 정보 표 + 조사원 해석 |
| **C. 데이터 기반 질문**| (그래프 이후) "왜 이 노드 크지?", "이 클러스터 성격?", "이 두 키워드 왜 연결?" | (기존 데이터 + 필요시 keyword_info 추가) | 대화형 답변 |

## 모드 A · 그래프 조회

### 사용자 확인 항목

1. 시드 (1~2개)
2. 국가 (gl)
3. orientation (기본 UNDIRECTED)
4. hop (기본 2)
5. **인라인 vs 파일** (기본 인라인 + 파일 fallback)

### 실행 · [[../../../references/cluster-finder-api.md]] 절차

### 응답 구성 (세 부분)

1. **조사원 요약** · 클러스터 개요·특이점 (사각지대 감지 · 3범주 등)
2. **핵심 데이터 표** · 상위 10~20 노드·클러스터별 (사용자 판정 근거 · [[analysis-questions.md]] A-5)
3. **인라인 그래프** · `_shared/render/inner-template.html` 템플릿에 데이터 주입 · 응답에 완전 HTML 삽입 (Claude Desktop 인라인 렌더)
4. **파일 fallback** · `run_explorer.py --rerender`로 파일 저장 · 인라인 안 뜨면 열기 안내

## 모드 B · 키워드 정보 조회

### 사용자 확인 항목

1. 키워드 (하나 or 여러 개 배치)
2. 조회 깊이:
 - **간단** (ads_metrics · 1cr/kw) · 볼륨·트렌드만
 - **전체** (all · 10cr/kw) · 볼륨·트렌드·인구·SERP·의도·시계열 (기본)
3. 국가 (gl)

### 응답 구성 (사용자 질문에 맞춰)

키워드 조회 결과를 <b>사용자 발화 유형에 매핑해서 답변</b>:

| 사용자 발화 | 조사원 답변 우선순위 필드 |
|---|---|
| "검색량 얼마?" | volume_avg · volume_total · 채널별(gg vs nv) |
| "트렌드 어때?" | volume_trend · monthly_volume 시계열 (12~24개월) |
| "누가 검색?" | demography · 성별·연령 비율 + 페르소나 추정 |
| "광고 경쟁 심해?" | competition_index · cpc · low/high_bid |
| "구매 의도 있어?" | intents (i/n/c/t) · t·c 강조 |
| "SEO 진입 가능?" | features · AI Overview·Featured Snippet·PAA + competition_index |
| "관련 콘텐츠 만들려면?" | features.f_people_also_ask_for + intents |
| "여러 키워드 비교" | 여러 키워드 · 표로 정리 (핵심 3~4 필드 컬럼) | **응답 형식**:
```markdown
### 「전기자전거」 조회 결과

**검색량**[실제 데이터]
- 월평균: 245,333 (Google 57K + Naver 189K · 네이버 강세)
- 누적 총합: 2,567,300
- 트렌드: -30% (하락 — 시즌·규제 요인 교차 확인 필요)

**소비자**[실제 데이터 · demography]
- 남성 72.9% · 여성 27.1%
- 30~50대 지배적 (40대 31.7% · 30대 27.2% · 50대+ 26.2%)

**검색 의도**[실제 데이터 · intents]
- Informational + Transactional 혼합 (i=1·t=1)
- 정보 탐색(면허·종류)과 구매 실행이 함께 걸리는 헤드텀

**SERP 특성**[실제 데이터 · features]
- AI Overview 노출 · CTR 하락 위험
- Featured Snippet 없음 · 유기적 진입 기회
- PAA·연관검색·로컬(매장) 블록 노출 · 콘텐츠 각도 힌트

**조사원 견해**
- 남성 30~50대 중심 시장 · 하락 트렌드의 원인(시즌 진폭 2.48× vs 규제)은 시계열로 분리 확인
- 면허·종류 등 정보 단계 대응 콘텐츠 유효
- AI Overview 대응 필요 · Featured Snippet 확보 기회
```

## 모드 C · 데이터 기반 대화형 질문

<u>이미 그래프를 조회한 후</u> · 사용자가 후속 질문. 기존 데이터 재활용 + 필요 시 keyword_info 추가.

### 질문 유형별 대응

#### C-1 · "왜 이 노드가 크지?"

1. 볼륨은 keyword_info로 확보
2. keyword_info(all) 추가 호출로 심화 (트렌드·인구·의도)
3. 조사원 해석: 볼륨·트렌드·의도 조합 관점

예:
> "「모토벨로 전기자전거」가 큰 이유는 그래프 최대 허브(연결 268)이자 전업 브랜드 — '모토벨로' 단독 쿼리만 월 48,356 · 후기·매장·모델명 파생 쿼리가 클러스터 247개 노드를 견인"

#### C-2 · "이 두 키워드는 왜 연결됐지?"

1. `rels` 배열에서 pair 확인
2. 두 키워드 모두 keyword_info(all) 조회
3. 공통 의도·인구·SERP 분석
4. 조사원 해석: 검색 세션에서 함께 등장 · 왜 연관될지 추정

#### C-3 · "이 클러스터의 성격은?"

1. 해당 community의 노드 리스트 · volume 상위
2. 각 노드 특성 종합 (필요 시 keyword_info 배치)
3. LLM으로 자연어 라벨링 (예: "모토벨로 후기·모델 비교 클러스터 · 전업 브랜드 중심")
4. 조사원 해석: 이 클러스터가 마케팅 관점에서 어떤 세그먼트인지

#### C-4 · "이 클러스터가 다른 것보다 큰 이유?"

1. 클러스터별 노드 수·볼륨 합계 비교
2. 상위 노드 keyword_info로 견인 요소 확인
3. 조사원 해석: 어떤 브랜드·니즈·트렌드가 이 클러스터를 견인하는지

#### C-5 · "이 시장의 페르소나는?"

1. 상위 볼륨 노드 20~30개 keyword_info(all) 배치
2. demography 필드 집계 (가중 평균 by volume)
3. 조사원 해석: 성별·연령 지배 세그먼트 + 근거 노드

#### C-6 · "이 클러스터의 SEO 진입 가능성?"

1. 클러스터 상위 노드 keyword_info(all) 배치
2. features 필드 집계 (AI Overview·Featured Snippet·PAA·경쟁)
3. 조사원 해석: 진입 우호/재검토/회피 판정

## 조사원의 답변 원칙 · 재확인

- **학습 데이터 발화 금지** · 반드시 DaaS 응답 근거
- **모든 수치 4-레이블 병기** · `[실제 데이터]`·`[추정]`·`[가정]`·`[데이터 공백]`
- **데이터 공백은 인정** · "이 키워드는 볼륨 미반환 · [데이터 공백]"
- **필요시 추가 API 호출** · 사용자 승인 없이 자동 호출 (크레딧 <100)
- **크레딧 100 이상 추가 호출은 승인 요청** · 사전 안내

## 대화 흐름 예시

```
사용자: 전기자전거 KR 클러스터 그래프 만들어줘

스킬: [모드 A · 그래프 조회]
→ cluster_finder + keyword_info → 인라인 그래프 + 요약

사용자: 「모토벨로 전기자전거」 클러스터가 왜 이렇게 큰 거야?

스킬: [모드 C · 데이터 기반 질문 · C-4]
→ 클러스터 노드 확인 → keyword_info로 견인 요소 확인 → 답변

사용자: 그럼 「삼천리 전기자전거」와 「알톤 전기자전거」 두 키워드 비교해줘

스킬: [모드 B · 키워드 정보 · 여러 키워드 비교]
→ keyword_info(all) 배치 2개 → 비교 표 + 조사원 해석
```

이 대화형 흐름이 이 스킬의 <b>핵심 가치</b>.
