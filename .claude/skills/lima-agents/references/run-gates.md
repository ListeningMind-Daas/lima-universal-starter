# 분석 건별 게이트 기록 (run-gates/v1)

> 2026-09-17 · 구현: `lib/gates.py` · CLI: `scripts/run_gate.py` · 테스트: 저장소 `tests/gates/` (있는 설치만)

**한 줄** — 신규 분석마다 파이프라인 게이트를 통과했는지 분석 폴더의 `gates.json`에 남기고,
렌더러는 렌더 전에, 발행(외부 전달·웹 내보내기)은 발행 전에 이 기록을 확인한다.

## 게이트 7개

| 게이트 | 파이프라인 | 단계 | 판정 |
|---|---|---|---|
| `budget` 예산 승인 | 6 | render | 자동 — 매니페스트 상한 안 소진이면 통과, 상한 없이 지출했으면 사람 기록(attest) |
| `canon` 정본 해석 | 6.5 | render | 자동 — COVERED면 통과. 정본 공백(PARTIAL·ABSENT·UNRESOLVED)이나 해석기가 없는 설치는 **결정 필요** → 사용자에게 묻는다 |
| `data` 수집·엔진 게이트 | 7~8 | render | 자동 — 엔진 게이트 '실패'가 있으면 실패, 경고는 근거에 기록. 엔진 밖 분석은 사람 기록(시드 검증 결과) |
| `readiness` 준비도 | 9 | render | 자동 — 어댑터 검증 오류는 실패. 품목 '미등재'(사전 공백)는 **결정 필요** → 사용자에게 묻는다 |
| `tests` 회귀 테스트 | — | render | 자동만 — `check`가 테스트를 돌린다. 사람이 통과로 적을 수 없다. 스위트가 없는 설치는 n/a |
| `labels` 출처 라벨 확인 | 10 | publish | 사람 기록 — 모든 수치에 실측·파생·가정·공백 라벨이 붙었는지 산출물을 보고 확인 |
| `rules` 규칙 회수 | 11 | publish | 사람 기록 — 새로 알게 된 판정을 규칙 등록부에 올렸거나(ID), 재확인했거나(ID), 없다는 사유 |

상태: `pass` · `fail` · `waived`(사유 필수 — 산출물 배너에 공개) · `pending` · `na`(자동 판정만) ·
`ask`(결정 필요) · `filling`(채우기 선택) · `skipped`(건너뛰기 선택).

## 사전 공백 — 실패가 아니라 질문이다

품목 사전·정본이 이 품목을 덮지 않는 것은 오류가 아니다. 게이트를 대기나 실패로 두지 않고 **결정 필요**로 두며,
에이전트는 **AskUserQuestion으로 "이 품목의 사전을 채울까요, 건너뛰고 진행할까요?"를 묻는다.**

| 사용자 답 | 기록 | 이후 |
|---|---|---|
| 채운다 | `run_gate.py decide --choice fill --by <이름>` → `filling` | 어댑터 사전(E0·brand-map)을 채우고 `check` → 통과로 바뀐다 |
| 건너뛴다 | `run_gate.py decide --choice skip --by <이름>` → `skipped` | 렌더를 막지 않는다. 산출물에 "사전 생략(사용자 선택) — 브랜드 귀속·정본 판정은 잠정" 한 줄만 남는다 |

크레딧을 쓰는 CEP Finder 실측 run은 사전 공백을 발견하면 **지출 전에 멈추고**(종료 코드 10) 이 질문을 먼저 받는다.
건너뛰기로 했으면 같은 명령에 `--on-dictionary-gap skip`을 붙여 재실행한다 — 엔진이 게이트에 `skipped`로 기록한다.
사람 기록(`source=manual`)은 `check`가 덮어쓰지 않고, 최신 자동 판정은 `auto_latest`로 옆에 남긴다.

## 흐름

```bash
G=.claude/skills/lima-agents/scripts/run_gate.py
python3 $G init   --run <분석 폴더> --vertical <버티컬> --category <품목>   # CEP Finder는 엔진이 run 끝에 자동 생성
python3 $G check  --run <분석 폴더>                                         # 자동 판정 갱신(회귀 테스트 포함)
# … 렌더 — 렌더 전 게이트 미통과면 렌더러가 멈춘다 (--allow-ungated: 미통과 배너를 넣은 초안)
python3 $G decide --run <분석 폴더> --choice fill|skip --by <이름>          # '결정 필요'가 나오면 사용자에게 묻고 기록
python3 $G attest --run <분석 폴더> --gate labels --by <이름> --note "<무엇을 확인했나>"
python3 $G rules  --run <분석 폴더> --by <이름> --reconfirm <규칙 ID> --note "<어디서 재확인>"   # 또는 --new / --none "<사유>"
python3 $G status --run <분석 폴더> --stage publish                          # 종료 코드 0이면 발행 가능
```

## 렌더러·발행 계약

| 상황 | 렌더러 (결정 리포트·범용 리포트·CEP 덱) | 발행 (외부 전달) |
|---|---|---|
| `gates.json` 없음 (2026-09-17 이전 run) | 막지 않음 · "게이트 기록 없음" 배너 | 막지 않음 · 배너 |
| 렌더 단계 미통과 | **중단** · `--allow-ungated`면 미통과 배너를 넣은 초안 | — |
| 발행 단계 미통과 | 렌더 · "발행 전 남은 확인" 한 줄 | **중단** · `--allow-ungated`면 배너 |
| 결정 필요(ask) | **중단** · 사용자에게 사전을 채울지 묻는 안내 | 같음 |
| 건너뛰기(skipped) | 막지 않음 · "사전 생략(사용자 선택)" 한 줄 | 같음 |
| 면제(waived) 있음 | 면제 항목·사유를 배너로 공개 | 같음 |

범용 스킬의 `render_report.py`·`render_cep_deck.py`는 `--run <분석 폴더>`를 받는다. 주지 않으면
"게이트 기록 미연결" 배너가 들어간다. lima-agents가 함께 설치되지 않은 단독 설치에서는 확인을 건너뛰고 경고만 낸다.

## 하지 않는 것

- 크레딧을 쓰지 않는다. 회귀 테스트도 0크레딧 스위트만 돌린다.
- 게이트 판정 기준을 바꾸지 않는다 — 각 게이트의 기준은 원래 계약(정본 해석·시드 검증·준비도 문서)이 정본이다.
- 사람 확인을 대신하지 않는다. `labels`·`rules`는 산출물을 본 사람의 기록이다.
