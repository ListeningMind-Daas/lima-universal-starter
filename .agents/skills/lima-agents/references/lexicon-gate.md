# 어휘·표현 게이트 v1.0 (2026-08-29)

> 리포트 등 **대외 보고 산출물**의 어휘·시각화 규율. 전수 감사에서
> 확정된 규칙만 담는다.
> 렌더러(`reports/cep-finder/render.py`)가 위반 후보를 경고로 출력한다(차단 아님 — 사람 판단 우선).
> 2026-09-17부터 분석 작업 용어는 §6 자동 검사가 **모든 빌더에서 차단**한다.

## 1. 금칙어 — 근거 병기 없이 사용 금지

| 계열 | 어휘 | 대체 |
|---|---|---|
| 자사 비하 | 완패 · 참패 · 소멸 · 궤멸 | "큰 격차 열세(수치 병기)" · "미미한 수준(N건)" |
| 지배 은유 | 독주 · 장악 · 석권 · (판을) 소유 · 접수 | "우위 지속(수치)" · "검색 지형 선점(여정 등장 기준 — 시장 점유 아님)" |
| 절대·단정 | 압도적 · 확실 · 반드시 · 입증됐다 | 수치 + 한정어("조회 범위 내") |
| 과장 동사 | 폭증 · 폭발적 · 급증(무근거) | "증가(+N% · 기간)" |

## 2. 의무 규칙

- **경쟁사명 + 부정어 인용**('<경쟁사> ○○ 대참사' 등): 소비자 검색어·CEP명 원문 인용임을 **첫 등장 또는 문서 서두에 라벨** — 리포트의 평가 어휘로 오독되지 않게 한다.
- **배수·%는 기저 병기**: "+3만%"처럼 저기저 급등은 "(사건성 급등 — 기저 N건·지속성 미검증)" 병기. 추세 계수(+1.5)는 "%"로 풀어 쓴다(+150%).
- **재무 용어 주석**: TAM·M(백만) 등은 "검색량 기준 — 시장 금액 아님" + 한글 단위(6,000만 건) 병기. "시장 규모" 제목 금지 → "검색 수요 규모".
- **유일·최초·1위는 범위 한정**: "조회한 플래그십 중" · "전체 120개 중 1위"처럼 분모·범위를 같은 문장에.

## 3. 시각화 규율 (2026-08-29 검증 기준 유지)

- 라인 차트 y축은 **0 기준선** (검증: 전 차트 통과) · 버블은 **면적 비례(r∝√값)** · 히트맵은 **전역 정규화**
- 비교 막대 정규화는 **전 계열 최대값 기준** (진영별·첫 계열 기준 금지 — 한쪽 우위가 축소돼 보인다)
- 미측정은 **점선 + "상속값/미측정" 범례** · 차트마다 단위·기간 표기 (캡처·발췌 대비)

## 4. 근거 (감사에서 판정된 오독 유형)

여정 비중을 시장 점유로 쓴 표현 · 실존하는 검색량을 '소멸'로 쓴 표현 · 지배 은유 · 검색량 TAM을 시장 금액처럼 쓴 표기 ·
저기저 급등률을 그대로 쓴 표기 · 비교 막대를 한 계열 기준으로 정규화해 우위가 축소돼 보인 차트.

## 5. 구어체 → 표준 용어 (2026-08-30 추가)

광고·검색 문맥의 구어체 **"자리"**는 대외 산출물에서 쓰지 않는다. 문맥별 표준 용어로 치환:

| 구어체 | 표준 용어 | 예 |
|---|---|---|
| 입찰/광고 "자리" | **지면** 또는 **입찰 검색어(군)** | "광고를 게재할 지면" · "저CPC 우선 입찰 검색어군" |
| SERP·AI 요약 "자리" | **지면** | "AI 요약 추천 지면" · "고유명 검색 지면" |
| 도달 가능한 "자리" | **검색어군 / 검색 수요** | "캠페인이 도달할 수 있는 검색 수요" |
| 판정 라벨 "검색 타겟(광고 자리)" | "검색 타겟(입찰 가능 검색어)" | 엔진 ROLE 문자열 (run_cep_finder.py) |

일상 공간 표현("주방에 자리가 없다")은 소비자 발화 인용이므로 유지한다. 또한 "가장 큰 자리"류의
**서수·규모 주장**은 용어와 별개로 데이터 검증 의무(실측 사례: 두 번째 축이 첫 번째 축보다 컸는데
"가장 큰"이라고 쓴 사실 오류).

## 6. 분석 작업 용어 자동 검사 (2026-09-17)

사전·코드: `lib/lexicon_check.py`(LEXICON · SAFE) · 파일 검사: `scripts/check_lexicon.py file <경로>…`

**왜** — 분석 작업 용어('질의'·'짝 시드' 등)는 업무 사용자가 읽지 못한다. 용어 사전이 한 산출물에만 있으면 다른 산출물에서 그대로 새어 나간다.

**두 층**
| 층 | 대상 | 처리 |
|---|---|---|
| 자동 치환(SAFE) | 뜻이 1:1인 용어 — 질의·쿼리→검색어 · 관계망·검색망→연관 키워드 · 군집→키워드 묶음 · 허브→진입점 · 슬롯→상황 요소 · 볼륨→검색량 · 매칭→일치 · 정본→기준 데이터 · run→분석 · AIO→AI 검색 요약 · 'N시드'→기준 검색어 N개 등 | 빌더가 출력 직전에 바꾸고 뒤 조사를 받침에 맞춘다(허브는→진입점은) |
| 다시 쓰기(차단) | 문맥 없이 못 바꾸는 용어 — 짝 시드 · L1/L2/L3(표기 구분인지 페이지 층인지) · 엔진 단계 코드(S0b·S5) | 렌더를 멈춘다. 작성자가 문장을 고친다 |
| 과장 표현(경고) | §1 금칙어 | 경고만 |

**검사 범위** — 화면 텍스트·페이지에 실린 데이터(JSON)·인라인 스크립트의 한글 문자열. 따옴표 안 소비자 검색어(‘…’)·`<code>`·URL·파일 경로·식별자 필드는 보지 않는다.
예외는 설정 `lexicon_allow {용어: 사유}` — 사유 없는 예외는 무시된다. 초안이 꼭 필요하면 빌더에 `--allow-jargon`.

**어디서 도는가** — CEP 결정 리포트(`reports/cep-finder/render.py`) · 범용 리포트(`render_report.py`) · CEP 덱(`render_cep_deck.py`).
손으로 만든 HTML·JSON은 `check_lexicon.py file <경로>`로 검사한다.

**치환 규칙을 넣을 때** — 치환 결과가 문법적으로 성립하는지 먼저 본다. '짝 시드→대표 모델명 기준 검색어'를 넣었더니 '짝 시드했습니다'가
비문으로 바뀌어 검사를 통과했다(테스트가 발견). 동사로 활용되는 용어·문맥에 따라 뜻이 갈리는 코드는 SAFE에 넣지 않는다.
