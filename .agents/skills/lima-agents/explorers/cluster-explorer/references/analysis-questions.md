# 마케팅팀 표준 분석 질문 프레임 (Ascent LM 마케팅팀)

**출처**: 마케팅팀 표준 조사 질문 프레임 (A~F)
**용도**: 사용자가 마케팅팀 프레임으로 질문할 때 · 스킬이 정확히 어떤 뷰·데이터로 답변할지 매핑

## 사용법

사용자가 "브랜드 인지도 분석해줘"·"라이징 브랜드는?"·"페인포인트 찾아줘" 같은 <b>마케팅팀 표준 언어</b>로 발화하면:

1. 아래 매핑 표에서 해당 질문 코드 찾음
2. 명시된 뷰·필드로 답변 조립
3. 답변 후 <b>관련 후속 질문</b> 자동 제시 (하단의 "가이드 질문 세트")

## 6개 대분류 · 마케팅팀 표준

| 코드 | 분류 | 우리 스킬 · 커버 정도 |
|---|---|---|
| **A**| 시장 흐름 · 검색 트렌드 및 시즈널리티 | 부분 |
| **B**| 타겟 심층 · 학령별/성별 인텐트 | 강력 |
| **C**| 브랜드 맵 · 라이징 브랜드·경쟁 구도·자사 포지셔닝 | 강력 |
| **D**| 전략 제안 · 인텐트 기반 전략 | 강력 |
| E | 광고·성과 | 커버 안 함 (별도 스킬) |
| F | 콘텐츠 · SERP 최적화 | 부분 (serp 커넥터) |

## 세부 질문 매핑 (A~D · cluster-finder가 답할 수 있는 것)

### A · 시장 흐름

| 코드 | 질문 | 우리 뷰·데이터 |
|---|---|---|
| A-1 | 메인 키워드 월별 검색량 추이·전년 대비 증감 | 부분 · `keyword_info.monthly_volume` (48개월) · 시계열 UI 없음 · 텍스트로만 답변 |
| A-2 | 메인 키워드를 누가 검색하나? | 모드 C · `keyword_info.demography` · 성별·연령 비율 답변 |
| A-3 | 소비자 검색 목적/인텐트 | **CEP뷰 WHY 카드** · 동기·목적 서브그룹 |
| A-4 | 인지→구매 검색 경로 | 이 스킬 밖 · path_finder 필요 |
| A-5 | 브랜드 비보조 인지도 (점유율) | **엔티티뷰 brands 카테고리** · 볼륨 순위 · ** 그래프뷰** 노드 크기 |

### B · 타겟 심층

| 코드 | 질문 | 우리 뷰·데이터 |
|---|---|---|
| B-1 | 학령별·성별 관심사·KBF 차이 | 모드 C · 상위 노드 `keyword_info(all).demography` 배치 조회 |
| B-1 매체 | 영향력 있는 매체 분석 | serp 커넥터 |

### C · 브랜드 맵

| 코드 | 질문 | 우리 뷰·데이터 |
|---|---|---|
| C-1 | 라이징/경쟁 브랜드 | **엔티티뷰 brands** · WebSearch 자동 검증 · ** 그래프뷰** 볼륨 |
| C-2 | 자사 vs 경쟁 검색 점유율 | **엔티티뷰** volume 비교 · ** 그래프뷰** 볼륨 시각적 비교 |
| C-3 | 자사 검색 전환/이탈 구간 | path_finder 필요 |
| C-4 | 자사·경쟁 페인포인트·부정 키워드 | **CEP뷰 HOW_FEEL**"부작용·우려" 서브그룹 |

### D · 전략 제안

| 코드 | 질문 | 우리 뷰·데이터 |
|---|---|---|
| D-1 | 카테고리 선점 CEP | **CEP뷰 전체** · 7W 진입점 (특히 WHY·HOW_FEEL) |
| D-2 | 검색 여정 노출 점유율 도메인 | serp 커넥터 |
| D-3 | 자사 강점/부족 검색 키워드 | **엔티티뷰 · 그래프뷰** · 자사 브랜드 vs 경쟁 볼륨·연결 |
| D-4 | 함께 검색되는 라이징 CEP·연관 아이템 | **CEP뷰 WITH_WHAT** · ** 그래프뷰** rels 관계 |

## 능동 인사이트 원칙 (매 응답 필수)

**사용자가 물어보기 전에 조사원이 먼저 발굴해서 지적**. 데이터만 보여주고 끝내면 실패.

### 5가지 능동 발굴 카테고리 (최소 3개 자동 선택)

각 카테고리마다 자동 발굴 로직 · 매 응답에서 활용:

#### 브랜드 지형 (C 프레임)
- 자문: "시장 지배 브랜드는? 격차는? 예상 밖 상위는?"
- 발굴: `detected_entities.brands` · 볼륨 순위 · 1위와 2위 격차 계산 · 국내/글로벌 브랜드 대조
- 지적 예: "모토벨로 단독 48,356 vs 삼천리 전기자전거 25,053 · 1.9배 — 전업 브랜드 단독 쿼리 포함 여부로 SoV 1위가 역전(24%→43%)함"

#### 리스크 신호 (C-4 프레임)
- 자문: "부작용·부정 검색 얼마나? 어느 브랜드에?"
- 발굴: CEP HOW_FEEL 서브그룹 중 부정적 카테고리 (LLM이 자동 발굴한 "부작용·우려"·"단점" 등) · 총 볼륨 · 특정 브랜드 언급 여부
- 지적 예: "부작용 검색 27건 (2,507 볼륨) · '신장·간 부작용' 우려 · 브랜드 진입 시 커뮤니케이션 필요"

#### 라이징 신흥 (D-4 프레임)
- 자문: "새로 뜨는 브랜드·CEP는? 스타트업 시그널은?"
- 발굴: `detected_entities.brands` 중 · 볼륨 낮지만 SNS·D2C 채널 감지 · WebSearch에서 "신흥·와디즈·크라우드펀딩" 언급
- 지적 예: "세발·삼륜 전기자전거 13,779/월 · ▲11~17% · 50대+ 45% — 하락 시장의 유일한 상승 세그먼트"

#### 기회 공백 (D-3 프레임)
- 자문: "어느 세그먼트가 비어있나? 대형 브랜드가 놓친 곳은?"
- 발굴: CEP 서브그룹 볼륨 극소 (전체 1% 미만) · 특정 W 자체가 비어있는지 · 대형 브랜드 관련 키워드 부재
- 지적 예: "WHOM 여성 결합 쿼리 190/월 (헤드텀의 0.1%) · 상위 브랜드 모두 미공략 · 진입 기회"

#### CEP 지배 (A-3 프레임)
- 자문: "어느 진입점이 시장을 지배? 편중 정도는?"
- 발굴: `cep_grouped` · W별 total_volume 순위 · 최대 W의 점유율 계산
- 지적 예: "WHY(동기) 33% (32만) 지배 · 그 중 '다이어트' 서브그룹 24만 · 대부분 검색이 다이어트 문맥"

### 능동 인사이트 응답 표준

```markdown
### 조사원 인사이트 (자동 발굴)

**1. [짧은 제목]**[데이터 + 왜 중요한가 · 마케팅 함의]

**2. [짧은 제목]**[데이터 + 함의]

... 최소 3개 · 최대 5개
```

### 절대 금지 (수동적 요약)

```
"노드는 1119개이고 클러스터는 22개이며 브랜드는 12개 감지되었습니다"
"이 데이터를 참고하세요"
데이터 나열만 · 함의 없음
```

### 필수 (능동적 인사이트)

```
"모토벨로 단독 48,356 vs 삼천리 전기자전거 25,053 · 단독 쿼리 취급 규칙에 따라 1위가 바뀜 [파생]"
"부작용 검색 27건 · 신뢰 리스크 · 진입 시 이 우려 해소 필수"
"여성 세그먼트 미커버 (190/월 · 0.1%) · 상위 브랜드 놓친 진입 기회"
```

## 가이드 질문 세트 (모드 A 응답 후 자동 제시)

모드 A (그래프 조회) 완료 후 · 응답 마지막에 **관련 후속 질문 5~7개** 자동 제시:

```markdown
**이 데이터로 답할 수 있는 후속 질문** (마케팅팀 프레임 기반):

시장·브랜드 (A·C 프레임)
- "이 시장의 라이징 브랜드는 누구야?" · 엔티티뷰 brands · volume 순위
- "자사 vs 경쟁사 점유율은?" · 엔티티뷰 · 그래프뷰 볼륨 비교
- "카테고리 내 검색 점유율 상위 5개는?" · 그래프뷰 hub_keywords

소비자 인텐트 (A·B·D 프레임)
- "소비자가 이걸 왜 검색해?" · CEP뷰 WHY 카드
- "부작용·부정 검색이 많은 브랜드는?" · CEP뷰 HOW_FEEL 부정적 서브그룹
- "라이징 CEP·연관 아이템은?" · CEP뷰 WITH_WHAT · 그래프뷰 rels

세그먼트 (B 프레임)
- "[특정 키워드]는 누가 검색해?" · 모드 C · keyword_info demography

전략 (D 프레임)
- "우리 브랜드 강점 키워드는?" · 엔티티뷰 자사 브랜드 · 관련 키워드
- "가장 큰 CEP 진입점은?" · CEP뷰 · 볼륨 최대 W
```

## 답변 형식 표준 (모드 C · 마케팅팀 프레임 질문)

사용자가 "A-3 인텐트" 같은 프레임 언어 or 자연어로 질문 시:

```markdown
### [질문 코드 참조 표시] 답변

[조사원 답변 · 데이터 근거 · 4-레이블 병기]

**근거 데이터** (Artifact 뷰 참조):
- [어느 뷰의 어느 부분에 나타남]

**추가 조사 필요** (있으면):
- [모드 C 추가 API 호출 · 크레딧 사전 안내]
```

## 정직성 원칙

- **답할 수 없는 질문은 그렇다고 명시** · 위 표에서 "필요" 항목은 다른 스킬 안내
- 예: "A-4 검색 경로는 이 스킬로 답 불가 · path_finder 스킬 필요"
- **부분 가능한 답변은 한계 명시** · 예: "월별 추이는 48개월 시계열 제공 · 전년 동월 비교 가능"
