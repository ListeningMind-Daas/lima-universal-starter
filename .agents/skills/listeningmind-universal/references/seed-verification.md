# 시드 검증 규칙 (② 계층) — 실측 전에 시드부터 검증한다

> 범용판 v2.0. 근거: 복수 산업·카테고리 실측(가전·식품·리테일 CS·CEP Finder 파일럿). 스크립트: `scripts/seed_check.py`.
> 판정 기록: `dictionary/seed_registry.csv`(append-only). 노이즈 사전: `dictionary/E0_사전.csv`(class=Noise) + `adapter.yaml` A2.

## 0. 왜

**시드가 오염되면 그 뒤 모든 실측이 낭비된다.** 여정·군집·연관어는 전부 시드에서 출발한다. 실측 사례:

| 시드 | 끌어온 것 | 비용 |
|---|---|---|
| `tv` | 방송·스트리밍(개수 25~38%, **볼륨 93%**) | 브랜드 판정 불가 |
| `이사` | 영화·직급·인물 — 137경로에 카테고리 0건 | 경로 전량 무효 |
| `에어컨장` | 밈 — 85경로 전량 | 폐기 |
| 품목 시드 REVERSE 여정 | 상황형 도달 5% | 20,500크레딧 손실 → 30크레딧 캔버스가 대체 |

공통 구조: **다의어가 헤드텀일 때 단독 시드는 다른 의미 영역을 끌어온다.**

## 1. 절차 — 3단계

**STEP 1 · 사전 조회 (0크레딧)** — `dictionary/E0_사전.csv`에서 후보를 찾는다. `Noise` 등재 → 폐기/대체.
`note`에 "동음이의어" → STEP 2 필수. 그 외 → STEP 2 권장(생략 시 사유 기록).

**STEP 2 · 저비용 프로브 (시드당 ~230크레딧)** — `intent_finder/keyword_list`로 연관어 100개를 수확해 지표를 낸다.

| 지표 | 정의 | 임계(기본) |
|---|---|---|
| **노이즈율** | 노이즈 패턴 매칭 쿼리 비율 | ≥20% → 교체 |
| **적합률** | **앵커 카테고리 어휘**(`--anchor`)를 포함한 쿼리 비율 | <60% → 교체 |
| **브랜드 히트** | 브랜드 사전 매칭 쿼리 수 | <10 → 통합 |
| (cs 모드) **CS 의도율** | 접점·이슈 어휘 비율 | <25% → 교체 |

**브랜드 히트는 사전이 있어야 잰다** — 새 카테고리는 브랜드 사전이 비어 있어 첫 프로브에서 히트 0이 나온다. 이건 오염이 아니라
사전 공백이다: `--dump`로 코퍼스를 저장 → 첫 토큰 빈도에서 브랜드 후보를 수확 → 분석 사전(`E0_<카테고리>.csv`, Brand/SubBrand 행) 작성
→ `--replay --dict E0_<카테고리>.csv`로 0크레딧 재채점한다(2026-08-22 전기자전거: 히트 0 → 28, 추가 크레딧 0).
비브랜드 카테고리(신선식품·서비스)는 `--skip-brand-gate`.

적합률은 **반드시 앵커 어휘 기준**으로 잰다. 시드 자기 어휘로 재면 자기충족 측정(전 시드 100% 통과)이 된다.
`path_finder`·`cluster_finder`를 쓰기 **전에** 통과시킨다 — 프로브 비용은 본 실측의 1~5%다.

**STEP 3 · 판정·조치**

| 판정 | 조건 | 조치 |
|---|---|---|
| 통과 pass | 노이즈 <20% · 적합 ≥60% · 히트 ≥10 | 사용 |
| 교체 replace | 노이즈 ≥20% 또는 적합 <60% | §2 규칙으로 대체 후 재프로브 |
| 통합 pool | 히트 <10 (볼륨 있으나 표본 부족) | 동류 시드 3~4개 풀링 |
| 폐기 discard | 대체로도 적합 <60% | 축 보류 · `Noise` 등재 |

판정은 `dictionary/seed_registry.csv`에 append — 다음 분석에서 같은 시드를 다시 시도하지 않게 하는 것이 규칙의 절반.

## 2. 시드 역할 — 게이트가 다르다

| 역할 | 코퍼스 | 게이트 | 비고 |
|---|---|---|---|
| `category`(기본) | 편입 | 노이즈·적합·히트 전부 | 품목·카테고리 시드 |
| `situation` 상황 앵커 | 비편입·여정 전용 | 노이즈율만 | 카테고리 도달률은 **측정 결과값** |
| `product` 제품 앵커 | 비편입·전이형 여정 | 적합률 면제 | 연관어 수는 특성값(표본 부족≠오염) · 상황형은 품목 run에서 상속 |

## 3. 대체 규칙 — 오염 유형별 (범용)

| 유형 | 금지 | 대체 | 근거 |
|---|---|---|---|
| 매체·플랫폼 다의 | tv · 채널명 · 앱 이름 | "○○ 추천"·스펙 결합·"best ○○" | 노이즈 25%→2% |
| 생애 이벤트 단독 | 이사 · 신혼 · 출산 | 이벤트 + 카테고리/행위 ("신혼 가전 리스트") | 137경로 0 → 결합형 15,105/월 |
| 공간·장소 단독 | ○○장 · 세탁실 · 사무실 | 별도 세션 조회(품목 여정과 혼합 금지) | 세션 분리 실측 |
| 문제·고민 단독 | 소음 · 전기요금 · 두통 | 문제 + 해결 동사/카테고리 | 피부과 14.3%→78.3% |
| 단위·일반명사 충돌 | 그램 · 드럼 · 미니 · 김 · 무 · 배 | 브랜드·품목 결합형 | 그램=무게 단위 |
| 채널·서비스명 충돌 | 당근 · 멜론 · 피망 | 카테고리 결합형("당근 효능") | 챗봇·앱·게임 충돌 |
| 속성·인증 단독 | 유기농 · 프리미엄 · 무료 | 속성 + 카테고리 | 범용 형용 |
| 밈·인물 | (발견 시) | 없음 — 폐기 | 85경로 전량 |

## 4. 범용 노이즈 어휘 (초기값 — 카테고리마다 `E0_사전.csv`에 append)

```
영어로 일본어로 한자 뜻 유래 나무위키 위키 wiki 채용 주가 로그인 게임 드라마 웹툰 가사 노래 영화 아이돌
편성표 다시보기 실시간 방송 뉴스 예능 중계 youtube streaming watch episode series subscription
```
커뮤니티 접미사("○○ 추천 디시"·"○○ 클리앙")는 노이즈가 아니라 **카테고리 의도 + RTB 원천**(2026-08-22 전기자전거 실측 오탐으로 확정). 기업 노드(채용·주가·로그인), 범용 커뮤니티·마켓플레이스 허브(ebay·best buy·쿠팡 단독)는 브랜드가 아니라
**채널/노이즈**로 분류한다. 콘텐츠 쿼리는 노이즈, 플랫폼 기기(fire tv·roku tv)는 브랜드 — 노이즈 판별과
브랜드 판별을 분리한다.

> ⚠ 개수 기준 노이즈율은 볼륨 오염을 과소평가한다(TV 25% vs 93%). 총량 지표는 **볼륨 기준**으로 재확인.
