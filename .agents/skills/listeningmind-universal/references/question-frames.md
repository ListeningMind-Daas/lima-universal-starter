# 질문 프레임 (① 계층) — 역할별 질문 카탈로그 · 발화 템플릿 · 범용 프레임 F1~F10

"같은 질문에 매번 다른 방식으로 답하지 않기" 위한 층. 새 발화가 오면 §3의 프레임 하나(또는 조합)로 매칭한다.
버티컬 오버레이는 이 파일을 복제하지 않고 **자기 프레임 파일**(예: `appliance-frames.md`)을 추가한다.

## 1. 역할별 표준 질문 카탈로그

| 역할 | 자주 묻는 것 | 프레임 |
|---|---|---|
| 브랜드매니저 | 우리 브랜드 존재감·경쟁 구도·어떤 맥락에서 소환되나·포지셔닝 갭 | F6·F3·F4 |
| 상품기획자 | 소비자가 따지는 기준·제약·회피·컨셉 화이트스페이스·근거 요건 | F3·F4·F9 |
| 퍼포먼스·콘텐츠 마케터 | 어떤 쿼리가 기회인가·비교 콘텐츠·광고 키워드·랜딩 요건 | F7·F5 |
| 이커머스·리테일 | 진입 경로·종착 채널·구색 공백·상세페이지 질문·CS로 새는 문의 | F5·F6·F10 |
| 소비자 인사이트 | 누가·어떤 상황에서·무엇을 못 풀고 있나·세그먼트 차이 | F3·F8 |
| 경영진·카테고리 리드 | 시장이 커지나·어느 세그먼트가 자라나·지금 들어가나 | F1·F2·F9 |

## 2. 발화 템플릿 — 문장별로 잠기는 분기

```
리포트· {브랜드/제품/카테고리} {국가} 시장 {분석 주제}
- gl={kr|us|jp} / {카테고리|세그먼트} 리포트 / 실행 주체: {브랜드 관점|중립 조사|경쟁사 관점}
- 잡: {주축 잡} 주축 + {보조 잡} 보강
- {상위 브랜드}와 {하위 라인}을 분리 비교 (해당 시)
- 크레딧 {N} 이내 / HTML 리포트 + Artifact
```

| 문장 | 없으면 |
|---|---|
| `리포트·` 프리픽스 | Explorer(탐색기)로 라우팅될 수 있음 |
| `카테고리 리포트`/`세그먼트 리포트` | 스파인이 뒤바뀜(TAM·구성 vs SoV·결정구조·여정) — 모호하면 질문 |
| `실행 주체: …` | **AskUserQuestion으로 중단** (리포트 필수 항목) |
| `gl=…` | kr 기본값으로 실행 |
| 상위/하위 분리 | 라인 간 차이가 사라짐 |
| `크레딧 N 이내` | cluster_finder 시드당 8~12만 소진 가능 — 예산 통제 필요 |

## 3. 범용 프레임 F1~F10 (질문 → 잡 → 커넥터 → 절차 → 산출 → 가드레일)

### F1. 수요 규모·추세·시즌
- **질문** "이 카테고리 검색이 얼마나 크고 어디로 가나? 언제가 피크인가?"
- **잡** 1 수요·트렌드 · **커넥터** keyword_info(all) · intent_finder(동의어 확장)
- **절차** 시드군 확정(동의어 dedup) → 24개월 차트+장기 방향 → YoY → 시즌 지수·진폭 → (kr) 채널 비중
- **산출** 수요 추이·시즌 카드 · KPI 4장
- **가드레일** 검색≠매출 · 시즌 품목 연평균 금지 · 롱테일 커버리지 배너

### F2. 시점 전후 비교 (정책·이벤트·런칭 임팩트)
- **질문** "○○ 발표/출시 전후로 검색이 어떻게 변했나?"
- **잡** 1 + 7 · **커넥터** keyword_info(time_point curr/3m/6m/12m) · cluster_finder(연관어 변화)
- **절차** 동일 시드군을 time_point별로 호출 → 볼륨·연관어 구성 비교 → 파생 니즈
- **가드레일** 인과 단정 금지(상관·동향) · 학습 데이터의 외부 사건 투사 금지 · `request_at` 명기

### F3. 카테고리 진입 상황(CEP) 발굴
- **질문** "사람들은 어떤 상황에서 이 카테고리를 찾기 시작하나?"
- **잡** 2 · **커넥터** intent_finder(캔버싱 프로브) → path_finder(상황 앵커) → cluster_finder
- **절차** 상황 패밀리(자기구매·선물·시즌·공간·전환) 어휘를 **상위 앵커**로 프로브(30크레딧/시드) → 결합 쿼리
  볼륨 → 여정에서 카테고리 도달률 측정 → 허브 조립(상황형/전이형 분기) → 부재는 캔버스 완주 후 `[실측]`
- **산출** CEP 카드(유형·근거 쿼리·볼륨·도달률) · 크로스 카테고리 패턴
- **가드레일** 상황은 품목 레벨에 없다(앵커 개방) · 속성≠CEP · CEP Finder 엔진이 있으면 `adapter.yaml`로 실행

### F4. 구매 결정 기준·컨셉 기회 (KBF·Constraint·Avoidance·RTB)
- **질문** "고를 때 뭘 따지고 뭘 피하나? 무엇을 보여줘야 믿나?"
- **잡** 2 (+5) · **커넥터** cluster_finder · keyword_info · serp(PAA·AIO)
- **절차** 군집→6층 분류 → 볼륨 검증 → CEP별 KBF 서열 → RTB 체인(주장·증거·출처) → 화이트스페이스
- **가드레일** 회피 요인은 우려 신호 · 규제 도메인 수치는 공표값만 · KBF 전역 상수 금지

### F5. 검색 여정·이탈·관문
- **질문** "어디서 들어와 어디로 새나? 비교 관문은 무엇인가?"
- **잡** 3 · **커넥터** path_finder · intent_finder · keyword_info
- **절차** 검증 시드 → 경로 150 → 단계 접기 → 허브·분기·이탈 → 마찰 노드 → 개입 포인트
- **가드레일** 집계 그래프 · 세션 인접 한계 · 크로스는 돈 붙은 이벤트에서만

### F6. 브랜드 검색 점유(SoV)·비교 소환(SoJ)
- **질문** "우리/경쟁 브랜드 존재감은? 비교 여정에 자사가 소환되나?"
- **잡** 4 · **커넥터** cluster_finder · intent_finder(모델명) · keyword_info
- **절차** 별칭 집합(×/○) → 모델명 수확 → 브랜드+모델 합산 → 채널 분리 → Generic 분리 → SoJ(비교 경로 동반률)
- **가드레일** "검색량 기준 근사" · 기업명 단독 제외 `[가정]` · 별칭 목록 공개

### F7. 콘텐츠·광고 키워드 기회
- **질문** "무엇을 써야 하고 어떤 키워드를 사야 하나?"
- **잡** 5 · **커넥터** intent_finder · keyword_info(CPC·SERP 피처) · serp
- **절차** 연관어 목적별 그룹 → 볼륨·CPC·노출 블록 → 구분 콘텐츠·비교표·FAQ·랜딩 요건 → 우선순위
- **가드레일** 카피는 초안(규제 도메인은 심의·준법검토 전) · 한 메시지 = 완결형 한 문장

### F8. 세그먼트·타겟
- **질문** "누가 검색하나? 세그먼트별로 무엇이 다른가?"
- **잡** 6 · **커넥터** keyword_info.demography(kr) · cluster_finder
- **절차** 성·연령 분포 → 세그먼트별 쿼리군·KBF 비교 → 격차·공백 → (us/jp) 과업 기반 대체
- **가드레일** 집계만 · 민감 속성 추정 금지 · us/jp 사양 배너

### F9. 진입·확장 판단 (카테고리 리포트)
- **질문** "지금 들어가도/늘려도 되나? 어느 세그먼트부터?"
- **잡** 7 · **커넥터** keyword_info → cluster_finder → path_finder(필요 시)
- **절차** TAM·세그먼트 구성(YoY) → 전체 SoV(Generic 분리) → Intent Mix → 관문·마찰 → 백로그
- **가드레일** 내부 데이터 필요 결정은 비워 둠 · 권고 단정 금지 · 확신 경계 명시

### F10. 정기 감시 (운영 모드)
- **질문** "○○ 검색 이상 생기면 알려줘 / 라이징 모니터링"
- **잡** 운영 스택(`ops-monitoring.md`) · **커넥터** keyword_info(월 1회) + 센티널 poll
- **가드레일** 월 그레인·3~7주 지연 — 주간 실시간 경보 아님 · 내부 데이터와 교차 검증 후 알림
