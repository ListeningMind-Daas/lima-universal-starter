# 엔티티 사전 — brand-map.md (범용 템플릿)

> 분석 대상 카테고리마다 이 파일을 복제해 채운다(`99_Scratch/<분석>/brand-map.md` 또는 오버레이의 `references/`).
> 표기 계약 `brand-map-md/v1`: `- **대표명 (영문)** — ×: 사명 별칭 / ○: 서브브랜드·제품 별칭` — 규칙은 `references/entity-dictionary.md`.
> ×(사명 별칭)는 단독 쿼리 SoV 제외, ○(서브브랜드)는 단독 유지. 대표명은 기업/브랜드 수준, kr은 한글 별칭 필수.

## 사용 원칙
1. 경쟁 브랜드 간 별칭 폭을 대등하게 — 카테고리 결합형("소니 tv")을 대표명으로 쓰지 않는다.
2. 단독 기업명 쿼리는 SoV 집계 제외 + `[가정]` 명시. 서브브랜드 단독은 유지.
3. 리포트 브랜드 행에 실제 매칭한 별칭 목록을 표기한다.
4. 브랜드가 아닌 것(채널·리뷰어·커뮤니티·기업 노드)은 아래 차단 목록에 두고 SoV 분모에서 제외한다.

### 브랜드가 아닌 것 — 차단 목록

- **리뷰어·커뮤니티**: {{예: 디시, 클리앙, reddit, 유튜브 리뷰 채널명}}
