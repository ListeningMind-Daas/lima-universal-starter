# 범용 가드레일 (③ 계층) · 규제 도메인 핸드오프

## 1. 모든 산출물에 강제 (adapter.yaml A5 `mandatory`와 동일)

1. **검색은 관심 신호** — 판매량·점유율·계약·방문·CS 인입이 아니다.
2. **SoV는 "검색량 기준 근사"** — 브랜드 우열 단정·비교광고성 표현 지양.
3. **null은 결측** — 0으로 환산하지 않고 `[없음]`.
4. **인과 단정 금지** — 이벤트·정책·시즌과 검색 변화는 상관·동향으로, `time_point` 전후 비교 근거 명시.
5. **임의 등급 금지** — 알고리즘이 주지 않은 HOT/급상승/high 라벨 금지, 통계 임계는 밝힘.
6. **집계 데이터만** — 개인 추적·개인정보·마이데이터 미사용. 검색 행동에서 민감 개인 속성(건강·종교·정치·성적
   지향 등)을 추정하지 않는다.
7. **출처 라벨** — `[실측]`/`[파생]`/`[가정]`/`[없음]`/`[fact]`. 근사·추정은 "정밀치 아님".
8. **월 그레인·지연** — 운영·모니터링 산출물에 "월 단위·3~7주 지연 — 주간 실시간 경보 아님" 표기.
9. **크레딧** — 소진(합산)과 월간 누적(`used_credits`)을 구분, 잔여량으로 제시 금지.
10. **카피·키워드는 초안** — 집행 전 확정 금지. 한 메시지 = 완결형 한 문장, 무출처 정밀 수치 금지.

## 2. 수치·주장 출처 규칙 (범용)

- 스펙·가격·금리·수익률·보험료·성분 함량·인증·시세 같은 **외부 사실**은 공시·공식·공표 출처만 `[fact]`로 인용.
  검색 데이터로 사실 여부를 판단하지 않는다.
- 최상급("가장 싼·조용한·빠른")은 측정값·시점과 함께만.
- 회피 요인(고장·부작용·환불)은 소비자 **우려 신호**이며 제품·서비스 결함 진술이 아니다.

## 3. 규제 도메인 추가 규칙 — 발화가 아래를 건드리면

| 도메인 | 신호 어휘 | 범용에서 처리 시 추가 규칙 |
|---|---|---|
| 금융(은행·증권·카드·보험) | 금리·수익률·한도·보장·대출·청약·가입 | 권유·단정 금지 · 수치는 공시/약관값만 · 카피는 "협회 심의+준법검토 전 초안" · 검색≠가입 |
| 건강기능식품·영양 | 효능·기능성·복용·유산균·비타민 | 효능 단정 금지 · 질병 예방·치료 표방 금지 · 섭취 권고 금지 |
| 화장품·뷰티 제품 | 앰플·성분·루틴·레티놀 | 화장품법 — 효능 단정 금지 · 의약품 오인 표현 금지 |
| 피부과·의료미용·의료 | 시술·기기·병원·의사·증상·치료 | 의료법 — 치료경험담·효과 보장 금지 · YMYL · 의료광고 심의 대상 표기 |
| 식품·신선 | 원산지·등급·인증·시세·보관 | 식품표시광고법 — 효능 표방 금지 · 원산지·인증은 공표값 · 리콜은 공식 발표만 |
| 가전 | 스펙·효율·설치·렌탈 | 스펙 공시값만 · 위생≠의료 효능 |
| 그 외 규제 접점(법률·주류·담배·도박·아동·채용) | — | 해당 법령 자문 필요 표기 · 광고 심의 대상 명시 · 민감 속성 추정 금지 |

처리할 때는 푸터 가드레일에 해당 행의 추가 규칙을 **그대로** 삽입한다. 해당 도메인 전용 오버레이 스킬이
설치돼 있으면 그쪽으로 라우팅하고, 경계 발화는 AskUserQuestion으로 확인 후 진행한다(즉시 실행 금지).

## 4. 산출물 삽입 확인 (렌더러 G4 게이트)

`render_report.py`는 A5 `mandatory` 문구 중 푸터에 빠진 것이 있으면 경고를 낸다. 경고를 지우지 말고 문구를 채운다.
